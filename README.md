# QIS - Quantum Inspired Simulations

CFD simulations using Tensor Network encoding.
This repository contains the implementations of the Quantum-Inspired CFD Algorithm of the paper: https://doi.org/10.1103/PhysRevResearch.7.013112
(arXiv link: https://arxiv.org/abs/2406.17823) with Julia

The algorithm was introduced in this paper by Gourianov et al.:
A quantum-inspired approach to exploit turbulence structures
https://www.nature.com/articles/s43588-021-00181-1

## File Descriptions

- simulation.ipynb - contains all steps to carry out a CFD simulation using the QIS algorithm
- animation.ipynb - shows how to visualize the Simulation Data
- src/2D_QIS.jl - contains source code for the algorithm
- src/visualization.jl - contains source code for data visualization
